# 台股 FVG 策略與掃描器

以 GainzAlgo「FVG with Probabilities」（台股改版）的邏輯為主，重寫成兩支 TradingView Pine Script：

- **策略**：訊號直接下單，用 TradingView 的「策略測試器」看績效。
- **掃描器**：一次掃 40 檔，結果排成表格，一個警報涵蓋全部。

只用原指標本身的東西，不接 LuxAlgo OB。要掃 Order Block，請用 [SMC OB 掃描器](https://github.com/gplee789-afk/SMC-ob-scanner-for-tradingview-v2)。

**名單工具（網頁版）：https://gplee789-afk.github.io/FVG-scanner-for-tradingview/**

依成交金額等項目排出前 400 檔，每 40 檔一批，複製後直接貼進掃描器的代號清單。用法見 [SMC OB 掃描器的說明](https://github.com/gplee789-afk/SMC-ob-scanner-for-tradingview-v2#名單工具說明)。

## fvg_prob_strategy.pine：策略

### 跟原版的差異

| # | 原版 | 這版 |
| --- | --- | --- |
| 1 | `Full Rebalance Mitigation` 沒作用 | 「影線回補 / 收盤穿越」兩種都會生效 |
| 2 | 早、中、尾盤加起來等於整個盤中，時段條件沒作用 | 三段可以個別勾選；預設全勾，跟原版相同 |
| 3 | 日線上開盤過濾把訊號全部擋掉 | 開收盤過濾只在日內週期生效 |
| 4 | 內部 OB 永遠不會消失，成立當根就能算回測 | 收盤穿越另一端或超過 100 根就移除；成立當根不算 |
| 5 | 盤中就畫標籤，收盤前可能消失 | 只在 K 棒收盤後成立 |
| 6 | 關掉的觸發仍算進分級 | 只算有開啟的觸發 |
| 7 | 等高低線、開盤區間、昨日高低、溢價折價區都畫在圖上 | 拿掉（跟訊號無關），溢價折價仍用在分數和訊號，只是不畫 |

訊號條件、分數公式和預設參數都跟原版相同，方便先拿原版的設定跑出基準。

### 下單規則（① 交易）

- 訊號在 K 棒收盤成立，下一根開盤進場。已有同方向部位就不加碼；反向訊號會反手。
- 停損：
  - 「前 N 根極值」（預設）：多單停在最近 3 根最低點下方 0.1 倍 ATR，空單反之。
  - 「ATR」：進場價往外 1.5 倍 ATR。
- 目標：2R。持有超過 50 根平倉（0 = 不限）。
- 「日內週期收盤前平倉」（預設關）：當天最後一根收盤時平倉，不留倉過夜。
- 交易方向：兩者 / 只做多 / 只做空。
- 成本在策略的「屬性」裡：每邊 0.2%（來回約 0.4%，含證交稅），可以自己改成實際的手續費折扣。
- 部位：每次用全部資金（屬性裡的「訂單大小」可改）。

### 怎麼用

1. Pine 編輯器 →「建立新的」→「策略」，貼上整份 `fvg_prob_strategy.pine`，按「新增到圖表」。
2. 圖表下方「策略測試器」看淨利、勝率、獲利因子、最大回撤和每筆交易。
3. **Basic 方案每張圖最多 2 個指標或策略**，要先移除一個才能加上。

## fvg_screener.pine：掃描器

版面和用法照 [SMC OB 掃描器](https://github.com/gplee789-afk/SMC-ob-scanner-for-tradingview-v2)的 `pine/smc_ob_screener.pine`：一次掃 40 檔、結果排成表格、一個警報涵蓋全部。每檔的判斷用上面策略的邏輯（FVG、分數、IFVG、內部 OB、掃蕩、訊號引擎）；因為 `request.security` 裡不能畫圖，掃描器裡是不畫框的純計算版。

### 怎麼用

1. 新建指標，貼上 `fvg_screener.pine`，加到圖表（會出現在下方獨立窗格）。
2. 設定「② 代號清單」貼上 40 行代號（用[名單工具](https://gplee789-afk.github.io/FVG-scanner-for-tradingview/)產生），格式是 `交易所:代號`，例如 `TWSE:2330`、`TPEX:6488`。
3. 圖表週期必須小於或等於「掃描週期」（預設 30 分）。

### 看表格

| 格子長這樣 | 意思 |
| --- | --- |
| `多 TRND A`（亮綠底） | 這根出現多方訊號，A+ / A / B 是分級；`REV` 是反轉訊號 |
| `多 H85% 1280–1290`（綠底） | 價格正在多方 FVG 裡；`IFVG` 表示是反轉缺口 |
| `多 ▼1.0% H85% 2470` | 最近的多方 FVG 上緣在 2470，還要再跌 1.0% |
| `空 ▲0.9% H85% 335` | 最近的空方 FVG 下緣在 335，還要再漲 0.9% |
| `–` | 沒有未失效的 FVG |

排序：有訊號 → 正在 FVG 裡（分數高的先）→ 距離最近。離 FVG 在「快碰到」門檻（預設 1.5%）以內會淡淡上色。

### 警報

新增警報 → 條件選這支 →「任何 alert() 函數呼叫」：

- 訊號（預設開）：出現 TRND / REV 訊號的那根收盤發出。
- 進入 FVG（預設關）：從外面進入分數 ≥ 65% 的 FVG 那根發出。

### 其他

- 「每檔計算幾根 K 棒」預設 1500，跑不動時降到 800。
- 「⑤ 訊號邏輯」只放主要參數，EMA 長度、RVOL 長度、IFVG 條件等固定用策略的預設值。要跟策略圖上的訊號一致，兩邊的參數要設成一樣。
- 現在的分數幾乎都打到上限 85%（表格裡大多是 H85%），代表原版公式太容易滿分、分辨力很低。

---

## 注意

- 分數是寫死權重的評分，不是機率。
- 原版預設的訊號條件很嚴（順勢要同時站上 EMA200、在折價區、確認 K 是強勢位移），30 分線上訊號可能很少，樣本不夠就看不出績效。
- 策略測試器只用圖上載入的歷史，換股票、換週期、多跑幾檔再下結論。
- 本專案僅供研究與學習，不構成任何投資建議。
